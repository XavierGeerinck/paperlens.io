DeepSeek mHC Protocol

Solving the Signal Survival problem in deep networks using Manifold Constrained Hyper-Connections.

Abstract

As networks get deeper (100+ layers), a fundamental physics problem emerges: signal survival. In standard architectures, information behaves like a game of telephone — it gets distorted, amplified to infinity (exploding gradients), or silenced to zero (vanishing gradients) as it passes through the layers.

DeepSeek's Multi-Head Latent Attention (MLA) and Manifold Constrained Hyper-Connections (mHC) papers propose a geometric answer. By forcing the weight matrices onto a specific mathematical manifold, the signal survives intact no matter how deep the network goes.

1. The "thinking highway" problem

Picture a neural network as a 100-storey building. Data enters on the ground floor and has to take the lift to the roof.

  • Wild mode (standard): the lift cables are rubber. Sometimes they stretch (amplify), sometimes they slacken (vanish). By floor 50 the passenger is either crushed by g-force or floating.
  • mHC mode (DeepSeek): the lift runs on a rigid track. The speed is mathematically constrained to be constant.

The mathematics of stability

In a standard dense layer the output y is:

y = W x(1)

If the eigenvalues of W are > 1, y grows exponentially with depth. If < 1, it shrinks. DeepSeek constrains W to be doubly stochastic:

Σj Wij = 1   and   Σi Wij = 1,   Wij ≥ 0(2)
  1. Every row sums to exactly 1.0
  2. Every column sums to exactly 1.0

The total "energy" of the signal is conserved. It is neither created nor destroyed — only routed. The simulation above measures exactly this: ‖xL‖ / ‖x0‖ as a function of depth L.

2. The algorithm: Sinkhorn–Knopp

How do you force a random matrix of weights to obey those rules? An iterative normalisation called the Sinkhorn–Knopp algorithm: normalise rows, normalise columns, repeat until stable.

python
def make_doubly_stochastic(matrix, iterations=5):
    """Project a positive matrix onto the Birkhoff polytope (approx.)."""
    for _ in range(iterations):
        # 1. rows sum to 1
        matrix = matrix / matrix.sum(dim=1, keepdim=True)
        # 2. columns sum to 1
        matrix = matrix / matrix.sum(dim=0, keepdim=True)
    return matrix

Five iterations are usually enough. This simple traffic rule lets DeepSeek train networks that are significantly deeper and wider than previous architectures without instability.

3. Scaling laws & efficiency

The constraint does more than stabilise training; it changes the scaling law. Because the signal doesn't degrade, smaller models using mHC punch above their weight class, reasoning with the depth of a much larger model.

"By forcing the matrix to be doubly stochastic, DeepSeek ensures that information is never lost and never amplified uncontrollably."
