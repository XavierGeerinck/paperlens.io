PaperLens: Visualized Papers and Research for AI Engineers

Xavier Geerinck

Scrydon, Belgium · xavier@m18x.com · github.com/xaviergeerinck

Abstract

Research papers describe mechanisms; readers rarely get to touch them. PaperLens is a growing collection of 28 entries in which a paper's central idea is rebuilt as a browser simulation with adjustable parameters, presented next to the derivation and the code. Each entry is tagged by maturity (research, prototype, alpha) and type (paper, deep-dive, idea), links to the source PDF, and runs entirely client-side1. Recent entries cover collapse-proof world models [1], near-optimal KV-cache quantization [2], and matter-wave lithography [3].

1Introduction

A figure in a paper is a single frozen point in a parameter space. The claim it supports is almost always about a region. The entries collected here (Section 3) replace the frozen figure with the region: a simulation the reader can drive, placed beside the mathematics that explains what they see and the code that produced it.

The collection is organised by date. Maturity labels follow a simple ladder — research (the mechanism is reproduced), prototype (it runs on real inputs), alpha (others have used it) — and are updated when an entry moves. Figure 1 shows three recent entries.

2Method

Every entry follows one recipe. (i) Read the paper and isolate the single mechanism that carries the result. (ii) Rebuild that mechanism in a few hundred lines of TypeScript with the paper's own defaults. (iii) Write the derivation in plain language, introducing each variable before it is used. (iv) List two or three parameter changes worth trying. Where a result cannot be reproduced at browser scale, the entry says so and shows the scaled-down version instead.
